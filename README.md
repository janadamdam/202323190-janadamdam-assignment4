# Jana Damdam – Personal Portfolio Web Application

## 📌 Project Overview

This project is a complete personal portfolio web application developed as part of Assignment 4.
It brings together all previous work into a polished and fully functional website that demonstrates my skills in web development.

The application showcases both my **professional projects** and **creative interests**, combining interactivity, design, and dynamic features into one platform.

---

## ✨ Features

* Personalized welcome overlay using localStorage
* Mode switching (All / Professional / Creative views)
* Dynamic project filtering
* Favorites system with persistent storage
* Tooltip guidance for improved user experience
* Scroll-based animations and interactive elements
* Pexels API integration for inspiration search
* Contact form with validation and error handling
* Responsive design for different screen sizes

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Pexels API

1. Clone the repository:

   ```bash
   git clone https://github.com/janadamdam/202323190-janadamdam-assignment4.git
   ```

2. Open the project folder

3. Run the project:

   * Open `index.html` in a browser
     OR
   * Use Live Server in VS Code
